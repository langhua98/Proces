# 视频拆帧 / 合成 iOS App 技术方案

> 形式：iOS App（.ipa），**所有处理都在手机本地完成**，不需要服务器，不联网。

## 1. 需求理解

| 步骤 | 说明 |
|---|---|
| ① 选择视频 | 从相册或"文件"App 中选一个视频 |
| ② 拆帧 | 把视频拆成每一帧图片，每张图 **右下角打一个小编号**（第几帧） |
| ③ 导出 / 修改帧 | 帧导出到相册或"文件"App，用户可用其他 App 修改 |
| ④ 导入帧并合成 | 把帧导入回来，按编号顺序合成视频，合成时 **可去掉编号**（可选保留） |
| ⑤ 保存视频 | 合成的视频保存到相册 / 分享 |

## 2. 技术选型（全部用苹果系统自带框架，不依赖第三方库）

| 模块 | 选型 | 说明 |
|---|---|---|
| 语言 / UI | Swift 5.9 + **SwiftUI** | 最低支持 iOS 16 |
| 选视频 / 选图 | `PhotosPicker`（PhotosUI）、`fileImporter`（文件 App） | 不需要申请完整相册权限 |
| 读取视频信息 | `AVURLAsset` | fps、分辨率、时长、帧数、旋转方向、音轨 |
| 拆帧 | **`AVAssetReader`** 逐帧解码 | 比 `AVAssetImageGenerator` 快且精确到每一帧 |
| 打编号 | **Core Graphics** / `UIGraphicsImageRenderer` | 在右下角画半透明底 + 白色数字 |
| 识别编号 | **Vision**（`VNRecognizeTextRequest`） | 文件名丢失时，读取右下角编号来确定是第几帧 |
| 去编号 | Core Graphics | 把原图对应区域贴回去 |
| 合成 | **`AVAssetWriter`** + `AVAssetWriterInputPixelBufferAdaptor` | H.264 / HEVC 硬件编码，速度快 |
| 音轨 | `AVAssetReader` 读原音频 → `AVAssetWriter` 写入 | 可选保留原声 |
| 保存相册 | `PHPhotoLibrary` | 只需"添加到相册"权限 |
| 数据存储 | App 沙盒目录 + JSON 元数据 | 项目列表、帧数、编号区域坐标等 |

## 3. 核心设计：编号怎么打、怎么删

编号是直接画在图片上的。删除时如果靠"识别+修图"去抹掉，效果差且不稳定。所以采用 **"保存原图小块 + 固定位置打编号"** 的方式，保证删除是**无损**的：

1. **打编号**：编号放在固定位置（右下角，距边缘 `margin`），字号随分辨率自适应（如视频高度 × 3%），样式为半透明黑底 + 白字（任何画面都看得清）。编号框坐标 `(x, y, w, h)` 写进项目元数据，所有帧都一样。
2. **只保存原图的那一小块**：拆帧时把每一帧原图编号框区域那一小块（比如 120×40 像素）单独存下来。整帧原图不另存（太占空间），原视频本身就是"干净原图"的备份。
3. **去编号**：合成时，按帧号找到这一帧对应的原图小块，**贴回**到用户导入的帧的同一位置。编号消失，这块与原视频完全一样，用户对画面其他地方的修改全部保留。
4. **怎么知道导入的图是第几帧**（按顺序尝试）：
   1. 文件名 `000001.png`（从"文件"App 导入时文件名会保留）
   2. 图片元数据：导出时把帧号写进 PNG/EXIF 元数据
   3. **Vision 识别右下角编号**：从相册导入时文件名会丢失，修图 App 也可能把元数据清掉，这时直接读图上的编号
   4. 都失败：按导入顺序，并提示用户确认

> 备选模式"边框编号"：不在画面内写字，而是在画面下方加一条边框，编号写在边框右侧，合成时直接裁掉边框。完全不碰原画面，缺点是导出的图片尺寸变了。在设置里做成可选项。

## 4. 处理流程

### 4.1 拆帧
```
选择视频（复制到 App 沙盒）
  → AVURLAsset 读取 fps、分辨率、旋转方向、总帧数
  → AVAssetReader 逐帧解码（CVPixelBuffer）
      ├─ 截取编号区域原图小块 → patches/000001.png
      └─ 画编号 → 编码为 JPG/PNG → frames/000001.jpg（写入帧号元数据）
  → 实时显示进度条
  → 完成后：在 App 内以网格方式浏览所有帧
```
- 逐帧处理、处理完立即写入磁盘并释放内存（`autoreleasepool`），避免大视频导致闪退
- 视频带旋转（竖拍）的，按 `preferredTransform` 转正后再处理

### 4.2 导出帧
- **导出到"文件"App**（推荐）：整个文件夹或 zip，文件名保留编号
- **导出到相册**：建一个以项目名命名的相簿，批量写入
- **分享**：系统分享面板（AirDrop 到电脑修改等）

### 4.3 导入帧并合成
```
从相册多选 / 从"文件"App 选文件夹或 zip 导入
  → 识别每张图的帧号（文件名 → 元数据 → Vision 识别 → 导入顺序）
  → 校验：尺寸是否一致、是否缺帧、是否重复
  → 显示校验结果，让用户选缺帧怎么处理：
       用原视频的帧补上 / 直接跳过 / 取消
  → 逐帧：（如需去编号）贴回原图小块 → 转 CVPixelBuffer → AVAssetWriter 写入
  → （可选）写入原音轨
  → 生成 output.mp4 → 预览播放 → 保存到相册 / 分享
```

合成参数（界面上的选项）：

| 选项 | 默认 | 说明 |
|---|---|---|
| 去掉编号 | 开 | 关掉则编号保留在视频里 |
| 帧率 | 原视频 fps | 可改，例如做慢动作 / 快放 |
| 保留原声 | 开 | 帧数变化时声音按视频长度截断 |
| 缺帧处理 | 用原帧补 | 用原帧补 / 跳过 / 取消 |
| 编码 | H.264 | H.264（兼容好）/ HEVC（体积小） |
| 画质 | 高 | 控制码率 |

## 5. 界面设计

```
首页（项目列表）
 ├─ [+] 新建：选择视频
 └─ 项目详情页
      ├─ 视频信息：分辨率 / fps / 帧数 / 时长
      ├─ 帧网格：缩略图 + 编号，点开看大图
      ├─ [导出帧] → 文件 / 相册 / 分享
      ├─ [导入帧并合成] → 校验结果 → 合成选项 → 进度条
      └─ 合成结果：播放预览、[保存到相册]、[分享]
设置：编号样式（位置 / 大小 / 颜色）、导出格式（JPG / PNG）、编号模式（画面内 / 边框）
```

```
    FrameImporter.swift      # 从相册 / 文件导入、校验

  Views/

    ComposeOptionsView.swift
    ProgressOverlay.swift
  Tests/                     # 打编号→去编号像素一致性等单元测试
```

沙盒中的数据：
```
Documents/Projects/{id}/
  input.mov            # 原视频
  meta.json            # fps、尺寸、帧数、编号区域
  patches/000001.png   # 编号区域原图小块（很小）
  frames/000001.jpg    # 带编号的帧
  imported/            # 导入的帧
  output.mp4           # 合成结果
```

## 7. 性能与限制

| 问题 | 对策 |
|---|---|
| **手机存储占用**：1080p 1 分钟 30fps = 1800 帧 | 带编号的帧默认存 JPG（每帧约 300KB，约 0.5GB）；原图只存编号小块（每帧几 KB）；开始前检查剩余空间并提示 |
| **内存**：一帧 4K 解码后约 33MB | 逐帧流式处理、`autoreleasepool` 及时释放，不一次性加载所有帧 |
| **速度** | AVFoundation 硬件解码 / 编码；打编号用 Core Graphics，按 CPU 核数并行 |
| **App 被切到后台** | 用 `beginBackgroundTask` 争取时间；被中断后从已完成的帧继续（断点续做） |
| **相册导入大量图片** | 分批加载，显示进度 |
| **HDR / 10-bit 视频** | 第一版统一转为 SDR 8-bit，在界面上提示 |

建议限制：单个视频不超过 4K、不超过 10 分钟（可在设置里调）。

## 8. 构建与安装 .ipa

- **需要一台 Mac + Xcode 15 以上** 才能编译出 .ipa（苹果的限制；当前这个云端环境是 Linux，只能写代码，不能编译）
- 安装到手机的方式（任选其一）：
  1. **免费 Apple ID**：Xcode 直接装到自己手机，签名 7 天后过期，需要重新装
  2. **付费开发者账号（99 美元/年）**：可用 TestFlight 分发，或打 Ad Hoc .ipa 装到登记过的设备，有效期 1 年
  3. 自签工具（AltStore / 爱思助手等）安装 .ipa
- 可以配置 GitHub Actions 的 macOS 机器自动编译出未签名的 .ipa，再用上面第 3 种方式签名安装
