# 视频拆帧 / 合成 iOS App 技术方案（v3：最新技术 · 极致流畅）

> 目标：iOS App（.ipa），用目前最先进的技术，做到 **拆帧、浏览、合成都非常快，滑动不卡**。
> 结论：**手机端 GPU / 硬件编解码为主 + 云端 GPU 为辅** 的混合架构。

## 1. 为什么不是"全放到云端"

| | 手机本地（GPU + 硬件编解码） | 纯云端 |
|---|---|---|
| 拆帧速度 | 1080p 约 **300–600 帧/秒**（A17/A18/M 系列芯片） | 服务器快，但要先上传视频 |
| 拿到帧 | 立即可见 | 1800 帧 ≈ 0.5–3GB，**要全部下载回手机**，最慢的就是这一步 |
| 合成 | 硬件 HEVC/H.264 编码，几秒到几十秒 | 要把修改后的帧再全部上传 |
| 网络 / 隐私 | 不需要网络，视频不出手机 | 依赖网速，有服务器成本 |

**真正的瓶颈是传输，而不是计算。** 现在的 iPhone 芯片自带专用的视频编解码硬件和强大的 GPU，在手机上处理比"上传 → 云端处理 → 下载"快得多、也流畅得多。
云端只用在手机做不了或不划算的场景：超长 / 8K 视频、旧机型、AI 修复、多设备同步。

## 3. 让它"极致流畅"的关键技术

### 3.1 "虚拟帧"：不预先生成上千张图片
旧做法是一上来就把所有帧解码、存成图片，又慢又占空间。新做法：

- 导入视频后 **1 秒内** 就能看到帧网格：先用硬件解码出低分辨率缩略图，看到哪里解到哪里（按可见区域优先）
- 点开某一帧时，再解码这一帧的全分辨率画面（GOP 缓存 + 前后预读，左右滑动没有等待）
- 只有用户点"导出"时，才真正生成带编号的图片文件，而且是后台流式导出，边导出边可以继续操作
- 原视频本身就是"干净原图"，不需要再存一份

### 3.2 GPU 零拷贝流水线
```
VideoToolbox 硬件解码 → CVPixelBuffer（IOSurface）
  → Metal 纹理（不经过 CPU 拷贝）
  → Metal 着色器叠加编号 / 贴回原图区域
  → 硬件 HEIC / JPEG 编码导出，或直接送给 AVAssetWriter 合成
```
整条链路数据都在 GPU / 专用硬件里流转，CPU 几乎不参与，所以快、省电、不发烫。

### 3.3 Swift 6 结构化并发
- 解码、打标、编码分成三段流水线（`AsyncStream`），并行处理
- 用 `TaskGroup` 按 CPU / GPU 负载自动调节并发数
- 随时可以取消、暂停、断点续做，界面线程永远不被阻塞

### 3.4 界面流畅
- 帧网格用 `LazyVGrid` + 预取 + 降采样缩略图，在 120Hz 屏幕上滑动保持 120fps
- 拖动时间轴实时预览（scrubbing），只解码关键帧 + 最近的帧
- 进度条、实时剩余时间、触感反馈；处理时锁屏可以通过 Live Activity（灵动岛）看进度

## 4. 编号：打上、删除

1. **在 App 内浏览时**：编号是一个**叠加图层**，不写进画面。开关随时切换，不存在"删除"的问题。
2. **导出图片时**：编号用 GPU 画在右下角固定位置（半透明底 + 白字，字号随分辨率自适应），坐标记进项目数据；帧号同时写进图片元数据。
3. **合成时去编号**（三级保障）：
   - ① **原图贴回**（默认，无损）：按帧号从原视频解出这一帧，把编号框区域贴回，像素与原视频完全一致
   - ② **只贴回没被改过的部分**：如果用户的修改覆盖到了右下角，逐像素对比，只还原"编号像素"，保留用户画的内容
   - ③ **AI 修复**（可选）：如果编号区域被大面积修改，手机端用 Core ML 修图模型，或云端用 LaMa 模型补全，自然地去掉编号残留
4. **识别导入的图是第几帧**：文件名 → 图片元数据 → Vision 读取右下角编号 → 导入顺序（让用户确认）。Vision 在神经网络引擎上运行，每帧只需几毫秒。

## 5. 处理流程

### 拆帧 / 导出
```
选择视频（相册 PhotosPicker / 文件 App / 分享扩展 / 拖拽）
  → 读取信息：fps、分辨率、HDR、旋转方向、音轨
  → 帧网格立即可用（虚拟帧）
  → 导出：GPU 打编号 → 硬件编码 HEIC/JPEG/PNG → 相册相簿 / 文件 App / zip / AirDrop
```

### 导入 / 合成
```
导入修改后的帧（相册多选 / 文件夹 / zip）
  → 识别帧号、校验尺寸、检查缺帧 / 重复，列出结果
  → 缺帧：用原视频帧补上 / 跳过 / 取消
  → GPU 去编号 → 硬件编码合成（HEVC / H.264 / ProRes），保留原声，支持 HDR
  → 预览播放 → 保存相册 / 分享
```
- 超长或 8K 视频、旧机型时，提示"使用云端加速"：视频分片断点上传 → 云端 GPU 处理 → 只下载最终视频

## 6. 技术栈清单

| 层 | 技术 |
|---|---|
| 语言 | **Swift 6**（严格并发检查） |
| 界面 | **SwiftUI**（iOS 18+），Observation 框架，Live Activity |
| 数据 | **SwiftData**，CloudKit 同步 |

| 工程 | Xcode 16、Swift Package 模块化、XCTest + Swift Testing、**GitHub Actions macOS 自动编译 .ipa** |

## 8. 性能目标（iPhone 15 / 16，1080p 30fps 1 分钟视频，1800 帧）

| 指标 | 目标 |
|---|---|
| 导入后看到帧网格 | < 1 秒 |
| 网格滑动 | 稳定 120fps |
| 导出全部带编号帧（JPEG） | < 15 秒 |
| 导入 1800 帧 + 识别帧号 | < 20 秒 |
| 去编号 + 合成 HEVC | < 15 秒 |
| 峰值内存 | < 300MB |

## 9. 构建与安装

- **编译**：配置 GitHub Actions 的 macOS 机器自动编译 .ipa，**不需要你自己有 Mac**
- **安装**：
  - 有苹果开发者账号（99 美元/年）：用 TestFlight 安装，最省事
  - 没有账号：下载未签名 .ipa，用 AltStore / 爱思助手等自签安装（免费 Apple ID 签名 7 天有效）
