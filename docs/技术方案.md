# 视频拆帧 → GPT 优化 → 合成视频 iOS App 技术方案（v5）

> 形式：iOS App（.ipa，在 GitHub Actions 上编译），视频最长 15 秒。
> 流程：
> 1. App 把视频拆成照片，每张右下角带编号
> 2. **你把照片交给 GPT 优化**
> 3. 把 GPT 优化后的照片导入 App
> 4. App 按编号排好顺序、去掉编号，合成视频

## 1. 结合 GPT 的特点，需要提前解决的 5 个问题

| 问题 | 原因 | 方案 |
|---|---|---|
| ① 照片太多 | 15 秒 × 30fps = 450 张，手动交给 GPT 工作量太大 | **抽帧**：默认每秒抽 4 张（15 秒 = 60 张），合成时用 AI 补帧补回到 30fps（第 3 节） |
| ② 编号会被 GPT "重画" | GPT 是重新生成整张图，画面里的编号可能被改掉、模糊，原图也就没法贴回 | 编号写在画面**下方加的一条黑边**的右下角，合成时**整条裁掉**，不碰画面（第 2 节） |
| ③ GPT 返回的尺寸和比例会变 | GPT 输出固定尺寸（如 1536×1024、1024×1536、1024×1024），视频是 16:9 / 9:16 | 导出前就把照片补边到 GPT 支持的比例，导入后按记录的位置精确还原（第 2 节） |
| ④ 导入后不知道是第几张 | 从 ChatGPT 下载的图片文件名是随机的 | 用苹果自带的文字识别（Vision）读黑边上的编号，识别不到再按文件名 / 导入顺序，让你确认 |
| ⑤ 连起来播放会闪 | GPT 每张单独生成，细节、颜色每次都略有不同 | 抽帧 + 补帧可减轻闪烁；另外做**颜色统一**和可选的**去闪烁**处理；并建议每次给 GPT 用同一段提示词 |

另外：GPT 输出的宽度约 1536 像素，比 1080p（1920 宽）还低。如果要更高清，可以在合成前加一步"AI 放大"（第 4 节，可选）。

## 2. 编号设计（核心）

```
导出给 GPT 的照片（以 16:9 视频为例，画布补成 GPT 支持的 3:2）：
┌──────────────────────────────┐
│                              │
│         原视频画面            │  ← 只有这块参与合成
│                              │
├──────────────────────────────┤
│ ■■■■■■■■■■ 黑边 ■■■■■ 0012 │  ← 编号区：黑底大号白字，右下角
└──────────────────────────────┘
```

- **编号区在画面外**：补边的部分刚好用来放编号，不额外浪费空间；编号用大号、高对比、等宽数字，GPT 不容易改坏，文字识别也接近 100% 准确
- **记录精确位置**：每个项目都保存"画面区域"在画布中的比例位置（如上方 0%–89%）
- **导入时还原**：
  1. 读取编号（Vision 文字识别）→ 知道是第几张
  2. 把 GPT 返回的图按比例缩放回导出时的画布大小
  3. 按记录的位置裁掉编号区 → 得到干净的画面
  4. 自动检查：GPT 如果把画面挪动或缩放了，用画面内容和原帧对齐（特征匹配），自动校正位置
- **给 GPT 的提示词模板**（App 里一键复制）：例如"优化这张照片的画质和细节，保持构图、人物、颜色不变，不要修改底部黑色区域和数字"
- 备选：编号直接画在画面右下角。去除时用原图那一块贴回，但 GPT 优化过的画面风格和原图不同，贴回去会看出痕迹，**不推荐**

## 3. 抽帧与补帧（减少工作量）

| 抽帧频率 | 15 秒需要交给 GPT 的张数 | 效果 |
|---|---|---|
| 每秒 2 张 | 30 张 | 适合慢动作、风景 |
| **每秒 4 张（默认）** | **60 张** | 大多数视频 |
| 每秒 8 张 | 120 张 | 动作较多 |
| 全部帧 | 450 张（30fps） | 最精确，工作量最大 |

- **智能抽帧**：画面动得多的地方多抽，基本不动的地方少抽；镜头切换的地方一定抽（App 自动分析）
- **补帧**：合成时用 AI 补帧模型（RIFE，转成 Core ML 在手机上运行），根据前后两张优化后的照片算出中间帧，恢复到 30fps 或 60fps
- 也可以不补帧，直接按低帧率合成（定格动画效果）

## 4. 合成

```
导入 GPT 优化后的照片（相册多选 / 文件 App / 直接从 ChatGPT 分享到本 App）
  → 识别编号、检查缺失和重复（缺的列出来，可以用原帧代替或重新交给 GPT）
  → 裁掉编号区、对齐位置、统一尺寸
  → 颜色统一（以第一张为基准，消除亮度、色调跳动）
  → （可选）AI 放大：1080p / 4K
  → AI 补帧到 30 / 60fps
  → （可选）去闪烁
  → 硬件编码 H.264 / HEVC，可保留原视频声音
  → 预览 → 保存到相册 / 分享
```

15 秒视频在 iPhone 上全部处理完的预计时间：不放大约 10–30 秒，放大到 4K 约 1–3 分钟（粗估，需要真机实测）。

## 5. 技术栈

全部在手机上完成，不需要服务器（所以不用 GPU 费用，也不需要联网，照片不经过第三方）：

| 模块 | 技术 |
|---|---|
| 语言 / 界面 | Swift 6 + SwiftUI（iOS 17+） |
| 拆帧 / 合成 | AVFoundation（AVAssetReader / AVAssetWriter）+ VideoToolbox 硬件编解码 |
| 补边、编号、裁剪、颜色统一 | Core Image + Metal（GPU） |
| 编号识别 | Vision 文字识别 |
| 位置对齐 | Vision 图像配准 |
| 补帧 / 放大 | Core ML（RIFE 补帧、Real-ESRGAN 放大），运行在神经网络引擎上 |
| 导入导出 | PhotosPicker、相册相簿、文件 App、分享扩展（从 ChatGPT 直接分享过来） |
| 数据 | SwiftData（项目、每张照片的状态：已导出 / 已优化 / 缺失） |

## 6. 界面

```
首页：项目列表 + [新建]
新建：选视频（≤15 秒）→ 选抽帧频率 → 预览会导出多少张
项目页：
  ├─ 照片网格：每张显示编号和状态（待优化 / 已优化 / 缺失），点开可以看原图 / 优化后对比
  ├─ [导出照片] → 存到相册新相簿 / 文件 App / 分享
  ├─ [复制提示词] → 粘贴到 ChatGPT
  ├─ [导入优化后的照片] → 自动识别编号，显示匹配结果
  └─ [合成视频] → 选项：帧率、补帧、放大、颜色统一、保留声音 → 进度 → 预览 → 保存
```

## 7. 以后可以加：自动调用 GPT（不用手动）

如果以后不想手动一张张交给 GPT，可以让 App 直接调用 OpenAI 的图片编辑 API：

- 一键把所有照片发给 GPT，自动收回，完全不用手动，编号识别也不需要了
- 需要你自己的 OpenAI API Key，按张计费
- API Key 不要直接放在 App 里，用一个小的中转服务（如 Cloudflare Worker）保存密钥，App 通过它调用

## 8. 编译与安装

- GitHub Actions 的 macOS 机器编译出 .ipa，在 GitHub 上下载
- 没有苹果开发者账号：编译**未签名 .ipa**，用 AltStore / 爱思助手 / 巨魔（TrollStore，部分系统版本可用）等自签安装
- 有开发者账号：配置证书后自动签名并上传 TestFlight

## 9. 代码结构

```
ios/
  project.yml               # XcodeGen 工程配置（不用 Mac 也能维护工程）
  App/
  Features/
    Projects/  Extract/  Export/  Import/  Compose/  Settings/
  Engine/
    FrameSampler.swift      # 抽帧（固定频率 / 智能）
    FrameExtractor.swift    # 解码出原帧
    LabelCanvas.swift       # 补边到 GPT 比例 + 黑边编号
    LabelReader.swift       # Vision 识别编号
    FrameRestorer.swift     # 缩放、裁掉编号区、对齐
    ColorMatcher.swift      # 颜色统一
    Interpolator.swift      # Core ML 补帧
    Upscaler.swift          # Core ML 放大（可选）
    Composer.swift          # 合成视频 + 音轨
  ShareExtension/           # 从 ChatGPT 直接分享照片到 App
  Tests/
.github/workflows/ios.yml   # 编译 .ipa
```

## 10. 开发计划

| 阶段 | 内容 |
|---|---|
| 1 | 工程 + GitHub 编译 .ipa；选视频、抽帧、黑边编号、导出到相册 |
| 2 | 导入、编号识别、裁剪还原、合成视频（不补帧）+ 声音 —— **到这一步就能完整用起来** |
| 3 | AI 补帧、颜色统一、智能抽帧、分享扩展 |
| 4（可选） | AI 放大、去闪烁、自动调用 GPT API |

## 11. 需要你确认

1. 你用的是 **ChatGPT App / 网页手动上传**，对吧？以后要不要做"自动调用 GPT"？
2. 默认**每秒抽 4 张 + 补帧**可以吗？还是一定要全部帧？
3. 编号放在**画面下方的黑边**里（合成时整条裁掉）可以吗？
4. 合成要保留原视频声音吗？
